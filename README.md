# ARVENTAS – Website-Prototyp

Off-Market-Immobilien, deutschlandweit. Vite + React.

- Übergabe an den Webdesigner: `docs/UEBERGABE.md`
- Medienverzeichnis: `docs/MEDIENVERZEICHNIS.md`
- Start: `npm install && npm run dev`, Build: `npm run build`, Tests: `npm run test:e2e`
- Indexierung: Build ist indexierbar, außer auf Vercel oder mit `SITE_INDEXABLE=false npm run build`

Prototyp mit Demo-Inhalten, nicht zur Veröffentlichung freigegeben.
